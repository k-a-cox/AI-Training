# Copilot Instructions

## User Preferences
- Use verbose/descriptive variable names and add a blank line between statements in code edits as a coding preference for this project.
- Do not commit changes automatically; only commit when explicitly requested.
- When requesting a commit, verify the intended complete change set against the prior commit and workspace, check git status and commit contents before declaring success, and ensure all related uncommitted changes are included or explicitly distinguished.
- When committing changes, only commit locally and do not push to remote repositories unless explicitly requested.
- When specifying an exact commit hash as the amendment target, use that commit rather than interpreting relative phrases like “two commits ago.”
- When changes in Git stashes have been verified as fully restored in the working tree or commits, clear the stashes rather than leaving redundant backups.
