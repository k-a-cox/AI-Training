# Step 5: Exercise the camera flow

- [ ] On a camera-capable device or suitable emulator setup, capture a puzzle and compare the recognized clues with the source.
- [ ] Correct at least one clue before confirmation and verify the accepted givens become locked.
- [ ] Verify conflict, no-solution, and multiple-solution rejections leave the scanned clues editable.
- [ ] Exercise camera denial, cancellation, an unreadable image, and a retry or return to manual entry.
- [ ] Run the Android build, focused unit tests, and relevant UI tests.

**Done when:** Camera entry works end to end, supports review and recovery, and uses the same confirmation rules as manual entry.
