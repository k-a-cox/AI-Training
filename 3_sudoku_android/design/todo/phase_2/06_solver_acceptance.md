# Step 6: Exercise the solver end to end

- [ ] Run the solver on a puzzle solved by logical techniques and verify the ordered explanations.
- [ ] Run the solver on a puzzle that requires backtracking and verify trial progress is distinguishable from logical deductions.
- [ ] Verify bounded solution counting can distinguish unique from multiple-solution puzzles for the deferred givens uniqueness check.
- [ ] Verify invalid input and a stuck result are reported distinctly.
- [ ] Cancel a run and edit the puzzle during a run; verify no stale result changes the current puzzle or progress.
- [ ] Run the Android build, unit tests, and relevant UI tests.

**Done when:** The solver works end to end with understandable progress, correct outcomes, cancellation, and no stale updates.
