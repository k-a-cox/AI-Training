# S.4 Compare Power BI Report Server

## Prerequisites

Core acceptance, host/resource/license review, and explicit installation/migration approval.

## Learning Goal

Distinguish Power BI Desktop, Power BI service, and on-premises Power BI Report Server.

## Allowed Scope

A development/test Report Server deployment and COPIES of report/model artifacts. Preserve the classic SSRS baseline.

## Actions

- [ ] Verify Developer/Evaluation rights and supported versions; no production entitlement assumed.
- [ ] Install approved Report Server and matching Report Server Desktop edition.
- [ ] Migrate a copy of SSRS RDL and compare parameters, permissions, exports, and data sources.
- [ ] Author/publish an eligible interactive report and document compatibility/refresh limits.
- [ ] Do not install a second SQL engine solely to claim modern reporting experience.

## Verification and Acceptance

When requested, compare visible results with baseline SSRS and standard Power BI Desktop. Keep separate backups and a rollback path; record migration limitations honestly.
