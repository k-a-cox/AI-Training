# Assignment 1: Personal Expense Tracker

This assignment uses VS Code Copilot throughout the development process:

- Generate a Python homework assignment.
- Use Copilot to help write the expense-tracker code.
- Test the program's outputs with valid, invalid, and edge-case inputs.
- Compare the completed implementation with the assignment requirements to verify the design is implemented.

## Project files

- `assignment.md` — assignment prompt, requirements, example session, and grading rubric.
- `expense_tracker.py` — interactive expense tracker implementation.
- `ai_expense_tracker.py` — alternative implementation.
- `ai_ExpenseTracker.cs` and `ai_ExpenseTracker.java` — additional language examples.
- `prompt_summary.md` — summary of prompts and development work.

## Run the Python program

From this folder, run:

```powershell
python expense_tracker.py
```

Enter an expense description and a positive amount when prompted. Type `done` at the description prompt to finish and display the summary.
